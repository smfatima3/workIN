# Prospective memory-to-contact diagnostic

Frozen before model outcomes on 5 November 2026. This experiment addresses the gap between a false claim surviving a reset and a robot contacting a person. The 24-trial scripted package only validated contact detection. Its results are kept separately.

The executor is the same downstream robot in every arm. A controlled source report says whether the central aisle is occupied. The relay model independently chooses whether to retain and share it. The executor independently chooses whether to store the relay's assessment. Source records, sessions and queues are then cleared.
